# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via [GitHub's private vulnerability reporting](https://github.com/interactive-studios/dockerized-highcharts-export-server/security/advisories/new). Do not open a public issue.

Vulnerabilities in the export server itself belong upstream at [highcharts/node-export-server](https://github.com/highcharts/node-export-server).

## Supported versions

Only the latest release receives fixes.
